# Earth textures

Both maps are NASA imagery, which is in the public domain. They were
resized with Pillow (Lanczos) and re-encoded as progressive JPEG; nothing
else was changed.

| File | Source |
|---|---|
| `earth-day-4096.jpg`, `earth-day-2048.jpg` | Blue Marble: Next Generation with topography and bathymetry, October 2004 (5400 x 2700). NASA Earth Observatory (Reto Stöckli), from MODIS data. |
| `earth-night-4096.jpg`, `earth-night-2048.jpg` | Earth at Night / Black Marble 2016 color map, 3 km (13500 x 6750). NASA Earth Observatory (Joshua Stevens), using Suomi NPP VIIRS data from Miguel Román, NASA Goddard Space Flight Center. |
