About

CTS-SAT-1, also called FrontierSat, is the first satellite built by the students of Calgary To Space. It launched on 3 May 2026. It carries two cameras: PiCAM, the main camera, which takes 640 × 480 frames, and the camera of the attitude determination and control system (ADCS), which takes 512 × 512 frames.

How a picture gets here

The satellite stores each picture as a file and sends it down in small packets, often over several passes. Amateur ground stations in the SatNOGS network record the passes, the CalgaryToSpace ground-station pipeline decodes the packets, and this gallery puts each file back together.

What the status means

verified
Every byte arrived, and the file's checksum (sha256) matches the one the satellite reported.
complete
The whole picture arrived, but the file can't be checked against the satellite: it reported no checksum, or a few bytes outside the picture are missing.
partial
Part of the file never came down. A main-camera picture is shown only down to its first missing line, because its JPEG can't be decoded past a gap. An attitude-camera picture shows grey bands where rows are missing.
cut short on board
The satellite stored only part of the frame because the capture stopped early, so the top of the picture is all there is. The copy here can still match the satellite's checksum for that shortened file.

Files that couldn't be shown

These image files are known from the satellite's logs or packets, but none of the picture can be shown.

    Times and positions

    The capture time comes from the file name, the camera's capture log, the capture command's own record, the attitude camera's file list, or the satellite's reply to the capture command. Some pictures only have a date. Most of these are readings of the satellite's own clock, which has run up to a couple of minutes fast; where the data shows how far off it was, the time is corrected for it. Positions are estimates: the point below the satellite at the capture time, computed with SGP4 from the most recent orbital elements (TLE) published before the capture. Place names come from OpenStreetMap (Nominatim).

    Edits from the team

    Team members can give a picture a title, notes, a place, the people involved and tags, and can correct its time or position. Edits are made on the team's own copy of the gallery and appear here when that copy is next published. The computed values are never overwritten, and every edited value is marked with the name of the person who changed it.
